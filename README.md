# Шпаргалка для демоэкзамена: Порядок запуска на машинах

> [!IMPORTANT]
> **Главное правило: НЕ ПАНИКОВАТЬ!**
> Просто открывайте виртуальные машины строго по очереди сверху вниз, заходите под `root` и запускайте указанный скрипт.

---

| :-: | :--- | :--- | :--- |
| **1** | **`ISP`** | `bash 01_isp.sh` | Настраивает интернет и NAT (маскарадинг) |

| **3** | **`BR-RTR`** | `bash 03_br-rtr.sh` | Настраивает стык с ISP, NAT и вторую сторону туннеля |
| **4** | **`BR-FW`** | `bash 04_br-fw.sh` | Настраивает файрвол филиала и маршрутизацию OSPF |
| **5** | **`HQ-SRV`** | `bash 05_hq-srv.sh` | Настраивает DNS-сервер и безопасный SSH (порт 2027) |
| **6** | **`BR-SRV`** | `bash 06_br-srv.sh` | Настраивает сервер филиала и SSH (порт 2027) |

## Как отредактировать файл, если в билете другие данные (30% изменений)

Если в билете другой порт SSH (например `2024` вместо `2027`) или другой пароль:

1. Откройте нужный файл в `nano`:
   ```bash
   nano 05_hq-srv.sh
   ```
2. В самом верху файла найдите блок переменных и измените значение:
   ```bash
   SSH_PORT="2027"     # замените на нужный порт
   OSPF_KEY="P@ssw0rd" # замените на нужный ключ OSPF
   ```
3. Сохраните: нажмите **`Ctrl + O`**, затем клавишу **`Enter`**.
4. Выйдите: нажмите **`Ctrl + X`**.
5. Запустите скрипт заново:
   ```bash
   bash 05_hq-srv.sh
   ```
